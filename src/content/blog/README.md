# Άρθρα του blog (`/blog/[slug]`)

Κάθε άρθρο είναι **ένα** αρχείο `.json` μέσα σε αυτόν τον φάκελο. Το όνομα του
αρχείου δεν παίζει ρόλο· το URL βγαίνει από το πεδίο `slug`.

Μόλις προστεθεί ένα αρχείο εδώ, το άρθρο εμφανίζεται **αυτόματα**:

- στη λίστα της `/blog`,
- στη δική του σελίδα `/blog/<slug>`,
- στο `sitemap.xml`.

Δεν χρειάζεται καμία άλλη αλλαγή στον κώδικα.

> Γιατί `.json` και όχι `.ts` όπως στις υπηρεσίες/παθήσεις; Επειδή τα άρθρα
> πρέπει να «ανακαλύπτονται» μόνα τους. Ο φάκελος διαβάζεται με `fs` κατά το
> build (βλ. `src/lib/blog.ts`), οπότε δεν υπάρχει κεντρικό `index.ts` που θα
> έπρεπε να ενημερώνεται με το χέρι σε κάθε νέο άρθρο.

## Δομή αρχείου

```jsonc
{
  "slug": "paradeigma-arthrou",           // το URL: /blog/paradeigma-arthrou
  "title": "Ο τίτλος του άρθρου",
  "date": "2026-09-02",                    // ISO ημερομηνία δημοσίευσης
  "category": "Αποκατάσταση",             // προαιρετικό label
  "excerpt": "Δύο γραμμές περίληψης· χρησιμοποιείται και ως meta description.",
  "image": "/images/back.jpg",             // αρχείο μέσα στο public/
  "imageAlt": "Προαιρετικό alt κείμενο",
  "body": [
    { "type": "heading", "text": "Μια ενότητα" },
    { "type": "paragraph", "text": "Μια παράγραφος." },
    { "type": "list", "items": ["Πρώτο", "Δεύτερο"] }
  ]
}
```

Τα `body` blocks είναι ακριβώς τα ίδια με αυτά των σελίδων υπηρεσιών/παθήσεων:
`heading`, `paragraph`, `list`.
